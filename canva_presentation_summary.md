# KEMRI Meeting Portal - Presentation Summary for Canva AI

## Project Title

KEMRI Meeting Portal: Streamlining Meeting Management for Kenya Medical Research Institute

## Project Overview

A modern web application built with Next.js that centralizes meeting management with authentication, Zoom integration, email notifications, and KEMRI branding. The portal allows staff to create, manage, and participate in meetings through a user-friendly interface.

## Key Features for Slides

1. **Authentication & Security**

   - Multiple sign-in options: Google, Microsoft, credentials
   - Secure session management with NextAuth.js
   - Protected routes and API endpoints

2. **Meeting Management**

   - Create meetings with comprehensive details
   - Filter and sort upcoming/past meetings
   - Support for different meeting types (internal, external, research, training)
   - Open and restrictive meeting options

3. **Zoom API Integration**

   - Automatic Zoom meeting creation
   - Meeting link generation
   - Invitation formatting and distribution
   - Synchronous meeting deletion

4. **Email Notifications**

   - SendGrid integration for reliable delivery
   - Professional HTML email templates
   - Automated invitations to attendees

5. **User Interface**
   - Responsive design using Tailwind CSS
   - Intuitive meeting creation form
   - Clean dashboard layout with KEMRI branding
   - Mobile-friendly experience

## Technical Architecture

1. **Frontend**: Next.js 15, React 19, Tailwind CSS 4
2. **Backend**: Next.js API routes with server-side rendering
3. **Authentication**: NextAuth.js with multiple providers
4. **Storage**: File-based JSON (planned database migration)
5. **External APIs**: Zoom, SendGrid
